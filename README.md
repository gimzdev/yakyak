# Yakyak

Sandbox for testing game balance changes before shipping them.

[Docs](https://docs.yakyak.dev) · Python · React · WebGL · SQLite

</div>


Try a balance change without touching the real game: import stats and formulas, tweak them, run
simulated matches and see what actually moves.

- **Mechanics**: damage, cooldowns, crits, resources and their curves, level scaling, items
- **Templates**: MOBA, card games, RTS, RPG, fighting games and battle royales
- **Results**: Monte Carlo runs over many matches, with win rates, matchups and outliers as charts

`Import → Modify → Simulate → Analyze → Export`
