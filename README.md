# Yakyak

Sandbox for testing game balance changes before shipping them.

[Docs](https://docs.yakyak.dev) · Python · React · WebGL · SQLite

</div>


Try a balance change without touching the real game.

| | |
|---|---|
| **Mechanics** | Damage, cooldowns, crits, resources and curves, level scaling, items |
| **Templates** | MOBA, card games, RTS, RPG, fighting games, battle royales |
| **Results** | Monte Carlo runs: win rates, matchups and outliers as charts |

`Import → Modify → Simulate → Analyze → Export`
